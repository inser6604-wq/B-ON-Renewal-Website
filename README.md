# B&ON Universe 자사몰 리뉴얼

## 프로젝트 개요

비앤온 유니버스의 Shopify 기반 기업 웹사이트 리뉴얼 프로젝트입니다. Dawn 테마를 초기 기반으로 사용하되, 기본 쇼핑몰 UI를 그대로 쓰지 않고 Figma 시안을 기준으로 커스텀 섹션과 인터랙션을 구현합니다.

이 사이트의 목적은 상품 판매가 아니라 **포트폴리오 신뢰 형성 → 서비스 이해 → 프로젝트 문의 전환**입니다.

## 시작 전 확인

- 테마: Shopify Online Store 2.0 / Dawn
- 템플릿 언어: Liquid
- 스타일: CSS
- 인터랙션: Vanilla JavaScript
- 폰트: Archivo, Pretendard
- 기준 디자인: B&ON 자사몰 리뉴얼 Figma
- 로고: 공식 로고 전까지 `B&ON UNIVERSE` 텍스트로 구현

## 권장 작업 순서

1. Dawn 테마를 개발 스토어로 가져온다.
2. 공통 폰트, 색상 토큰, 헤더/푸터를 만든다.
3. 홈 섹션을 Figma 순서대로 구현한다.
4. Portfolio 페이지와 공통 프로젝트 미리보기 팝업을 구현한다.
5. Service와 Contact 페이지를 구현한다.
6. Theme Editor에서 콘텐츠가 수정되는지 확인한다.
7. 데스크톱/태블릿/모바일 QA 후 preview theme에서 검수한다.

## 작업 규칙

- 라이브 테마에서 직접 수정하지 않는다. 항상 개발/프리뷰 테마에서 확인한다.
- 반복 콘텐츠는 하드코딩하지 않고 Shopify section schema의 block으로 만든다.
- Figma의 고정 px는 시각 기준으로만 참고하고, 구현은 반응형 `clamp`, grid, flex를 우선한다.
- `B&ON-Renewal-Hompage` 안의 원본 이미지/HTML은 초기 작업에서 삭제·이동·수정하지 않는다.
- `.env`, 토큰, 스토어 비밀번호는 Git에 올리지 않는다.

자세한 화면 기준은 `design.md`, 기능/콘텐츠 기준은 `PRD.md`, Shopify 구현과 schema 기준은 `TRD.md`를 확인합니다.
